# My Portfolio

## Project Description

This portfolio website showcases my web development work and the skills I have learned using HTML and CSS. The website includes information about me, examples of my work, and a responsive contact form.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Responsive web design
- GitHub Pages
- XAMPP

## Features

- Responsive webpage layout
- Portfolio information
- Contact form
- Flexible design for different screen sizes
- Online hosting through GitHub Pages
- Local hosting through XAMPP
